Este juego consiste en adivinar el código oculto de tu rival ya sea la computadora o otro jugador online.
este código debe ser previamente seleccionado por cada participante en mod multijugador.
en el modo contra computadora, esta ultima generara el código a adivinar.
El jugador tratara de adivinar el código proporcionando los elementos que crea debe tener el codigo.
Si alguno de los elementos esta en la posición correcta será un acierto.
Si alguno de los elementos esta en el código pero no en la misma posición será una posición incorrecta.
Si alguno de los elementos proporcionados no esta en el codigo se ignorara.
El historial mostrara cuantos elementos están en posición correcta y cuantos en la incorrecta. los que no aparecen no se cuentan.
